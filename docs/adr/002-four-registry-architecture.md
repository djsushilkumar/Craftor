# ADR 002: Four-Registry Unified Architecture

## Status

Accepted

## Context

Standard Model Context Protocol (MCP) implementations only provide a static, flat list of functions. However, complex web development requires domain specialization, prompt few-shots, autonomous agent personas, and deterministic multi-step workflows.

## Decision

Craftor unifies all platform capabilities into **4 First-Class Registries**:

1. **Tool Registry:** 240+ Versioned MCP tools (40 in MVP -> 100 -> 160 -> 240+) with JSON Schema Draft-07 contracts.
2. **Skill Registry:** 15 Antigravity specialized domain skills, system prompts, and automated benchmark evals.
3. **Agent Registry:** Autonomous role personas (Visual Designer Agent, Full-Stack Dev Agent, E-Commerce Ops Agent) with scoped guardrails.
4. **Workflow Registry:** Declarative Directed Acyclic Graph (DAG) chains with transactional rollback safety.

## Consequences

- Transforms Craftor into an extensible AI Operating System for WordPress.
- Enables marketplace distribution of skills, agents, and workflows.
- Establishes a permanent competitive moat over EMCP and Novamira.
