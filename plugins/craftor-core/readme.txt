Autonomous Model Context Protocol (MCP) server & real-time Elementor canvas sync engine for AI agents (Cursor, Claude Desktop, Antigravity, VS Code).

== Description ==

**Craftor Core** turns WordPress & Elementor into an AI-controllable headless canvas. It exposes a secure, bidirectional JSON-RPC 2.0 interface connecting modern AI coding agents and LLMs directly to your Elementor design tree.

### Key Features:
* **68+ Native MCP Tools:** Full programmatic control over Elementor Containers, Flexbox, Widgets, Global Kits, and Templates.
* **Live-Sync Canvas Overlay:** Watch AI agents synthesize, modify, and style sections in real-time inside your active Elementor editor.
* **Atomic Micro-Snapshots & Rollbacks:** Instant 1-click state recovery for pages, templates, and WooCommerce catalogs.
* **WooCommerce AI Engine:** Automate products, inventory, orders, customer segments, and dynamic coupons.
* **Multimodal Wireframe Synthesis:** Convert visual layout descriptions into production-ready Elementor AST containers.
* **Zero-Trust Security Shield:** Proactive protection against malicious code execution and prompt injection attempts.

== Installation ==

1. Upload the `craftor-core` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to **Craftor AI -> Settings** to generate your secure MCP token.
4. Add the connection to your AI Client (Claude Desktop, Cursor, Antigravity, etc.).

== Frequently Asked Questions ==

= Does Craftor require Elementor Pro? =
No. Craftor works with both Elementor Free and Elementor Pro containers.

= Which AI clients are supported? =
Craftor supports 8 major AI clients: Cursor, Claude Desktop, Antigravity, VS Code, Claude Code CLI, Codex, Windsurf, and JetBrains IDEs.
